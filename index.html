Performance / Windows 11

Windows 11, made lighter.

Twelve reversible optimisations in one small signed package. No system files deleted, no reboot required.

Download latestSource

Features

Applied in one pass, each change is a registry value or service start type and can be undone.

  • Disable telemetry & data collection
  • Disable unnecessary startup apps
  • Disable unnecessary services
  • Optimise visual effects
  • Disable tips, tricks & suggestions
  • Optimise SSD drives
  • Disable hibernation
  • Clean temporary files
  • Disable background apps
  • Optimise network
  • Optimise search indexing
  • Optimise memory management
