Everything in 26H2.3

The biggest release so far. Twelve optimizations grouped into privacy, performance and storage — all reversible with a single command.

Faster startup

Unneeded startup apps are removed from the boot path.

Private by default

Telemetry, tips and content suggestions are switched off.

Lower idle load

13 background services disabled, freeing CPU and RAM.

Fully reversible

Every change can be undone from the included Undo guide.

12 optimizations, one package

Each change targets a known source of background load in Windows 11. Nothing is deleted, and system files are never modified.

Disable telemetry

Stops diagnostic reporting and data collection to reduce background activity and improve privacy.

Disable startup apps

Removes OneDrive, Skype, Cortana, Teams and Xbox from the startup path.

Disable services

13 unnecessary services disabled, including DiagTrack, SysMain, WSearch and MapsBroker.

Optimize visuals

Switches visual effects to performance mode for snappier window and menu response.

Disable tips

Turns off Windows tips, tricks and content delivery suggestions.

Optimize SSD

Re-trims solid-state drives and disables scheduled defrag on SSDs.

Disable hibernation

Frees disk space equal to the size of your installed RAM.

Clean temp files

Removes temporary files and the Windows Update download cache.

Disable background apps

Prevents packaged apps from running while you are not using them.

Optimize network

Enables TCP autotuning, RSS, chimney offload and ECN for lower latency.

Optimize search

Reduces search indexing to essential locations only.

Optimize memory

Disables paging executive and tunes the page file for smoother multitasking.

Install in under a minute

Pick a method, copy the command, and run it in an elevated PowerShell window. No reboot is required.

1

Download the package

Grab the latest release ZIP from GitHub. It is small and contains the signed installer.

Download
https://github.com/GoStudios-Real/Windows11Update/releases/latest/download/Windows11FastLight-Package.zip
2

Extract and run

Right-click Windows11FastLight-Setup.ps1 and choose Run with PowerShell as administrator.

PowerShell — Administrator
powershell -ExecutionPolicy Bypass -File "Windows11FastLight-Setup.ps1" -Silent
1

Open an elevated terminal

Press Win + X and choose Terminal (Admin).

2

Download, extract and install

This one block does everything in a temporary folder.

PowerShell — Administrator
Invoke-WebRequest -Uri "https://github.com/GoStudios-Real/Windows11Update/releases/latest/download/Windows11FastLight-Package.zip" -OutFile "C:\temp\update.zip"
Expand-Archive "C:\temp\update.zip" -DestinationPath "C:\temp\update" -Force
powershell -ExecutionPolicy Bypass -File "C:\temp\update\Windows11FastLight-Setup.ps1" -Silent
1

Trust the certificate

Optional. Imports GoStudios.cer into Trusted Root and Trusted Publisher so the signature verifies.

PowerShell — Administrator
powershell -ExecutionPolicy Bypass -File "Trust-GoStudiosCert.ps1" -CerPath "GoStudios.cer"
powershell -ExecutionPolicy Bypass -File "Windows11FastLight-Setup.ps1" -Silent
2

Confirm the signature

Check that the installer is signed before running it.

PowerShell
Get-AuthenticodeSignature ".\Windows11FastLight-Setup.ps1" | Select-Object Status, SignerCertificate
The package only changes registry values and service start types. It never deletes system files. Run it as administrator, and use the Undo section below if you change your mind.

Verify it installed

PowerShell
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Windows11FastLight" |
  Select-Object DisplayName, DisplayVersion

Get-Service -Name DiagTrack, SysMain, WSearch |
  Select-Object Name, Status, StartType

Undo everything

PowerShell — Administrator
Set-Service -Name SysMain -StartupType Automatic
Set-Service -Name WSearch -StartupType Automatic
powercfg /h on
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\DataCollection" -Name "AllowTelemetry" -Value 1
