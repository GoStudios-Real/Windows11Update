What It Does

🔒
Disable Telemetry
Turns off data collection and diagnostic reporting to improve privacy and reduce background activity.
🚀
Disable Startup Apps
Removes unnecessary startup programs like OneDrive, Skype, Cortana, Teams, and Xbox.
⚙️
Disable Services
Disables 13 unnecessary services including DiagTrack, SysMain, WSearch, MapsBroker, and more.
🎨
Optimize Visual Effects
Sets visual effects to performance mode for faster UI response.
💡
Disable Tips & Suggestions
Turns off Windows tips, tricks, and content delivery suggestions.
💾
Optimize SSD Drives
ReTrims SSDs and disables scheduled defrag for solid-state drives.
💤
Disable Hibernation
Frees disk space equal to your RAM size.
🧹
Clean Temp Files
Removes temporary files and Windows Update cache.
🔇
Disable Background Apps
Prevents apps from running in the background.
🌐
Optimize Network
Enables TCP autotuning, RSS, chimney, and ECN for faster network.
🔍
Optimize Search
Reduces search indexing to essential locations only.
🧠
Optimize Memory
Disables paging executive and optimizes page file for better memory management.

Install

Option 1: Direct install (recommended)

powershell -ExecutionPolicy Bypass -File "Windows11FastLight-Setup.ps1" -Silent

Option 2: Download via PowerShell


Invoke-WebRequest -Uri "https://github.com/GoStudios-Real/Windows11Update/releases/latest/download/Windows11FastLight-Package.zip" -OutFile "C:\temp\update.zip"
Expand-Archive "C:\temp\update.zip" -DestinationPath "C:\temp\update"
powershell -ExecutionPolicy Bypass -File "C:\temp\update\Windows11FastLight-Setup.ps1" -Silent

Option 3: Trust cert first (for signed verification)


powershell -ExecutionPolicy Bypass -File "Trust-GoStudiosCert.ps1" -CerPath "GoStudios.cer"
powershell -ExecutionPolicy Bypass -File "Windows11FastLight-Setup.ps1" -Silent



Verify


Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Windows11FastLight" | Select-Object DisplayName, DisplayVersion
Get-Service -Name DiagTrack, SysMain, WSearch | Select-Object Name, Status, StartType



Undo (if needed)


Set-Service -Name SysMain -StartupType Automatic
Set-Service -Name WSearch -StartupType Automatic
powercfg /h on
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\DataCollection" -Name "AllowTelemetry" -Value 1





Frequently Asked Questions


Is this safe to install?
Yes. All changes are registry and service modifications that can be reversed. No system files are deleted or modified. The installer is signed with a code-signing certificate.


Will this break Windows Update?
No. Windows Update services remain enabled. Only unnecessary background services are disabled.


Can I undo the changes?
Yes. See the Undo section above, or re-enable services manually.


Does this work on Windows 10?
This update is designed for Windows 11. Some optimizations may work on Windows 10 but are not tested.


How much disk space does it free?
Disabling hibernation frees disk space equal to your RAM size. Cleaning temp files typically frees 1-5 GB.


Will my PC be faster?
Yes. Disabling telemetry, background apps, and unnecessary services reduces CPU and disk usage. Optimizing visual effects and memory management improves responsiveness.


Is this from Microsoft?
No, this is a community-created update by GoStudios, based on Microsoft's official Windows 11 specifications. It is not affiliated with Microsoft.


How do I verify it installed?
Run: Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Windows11FastLight" | Select-Object DisplayName, DisplayVersion
